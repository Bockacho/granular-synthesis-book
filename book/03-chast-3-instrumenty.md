## Часть 3. Три инструмента

Каждая глава этой части устроена одинаково: где живёт гранулятор, как загрузить звук, где в интерфейсе стоят параметры из части 2, скрытые меню, модуляция, рецепты на ложке. Повторение структуры работает на тебя: принцип один, меняется только расположение ручек.

### Глава 10. Xfer Serum 2

В Serum 2 гранулятор живёт внутри осциллятора. Любой из трёх основных осцилляторов (OSC A, OSC B, OSC C) переключается в один из пяти режимов: Wavetable, Multisample, Sample, Granular, Spectral. Значит, в одном патче можно держать до трёх независимых грануляторов, а рядом ещё саб и шумовой осциллятор.

> Описание соответствует Serum 2 версии 2.0.18. Учти: руководство предупреждает, что гранулярный режим нагружает процессор сильнее режимов Wavetable, Sample и Multisample.

*Скриншот 10.1. OSC A в режиме Granular с загруженным звуком. Интерфейс Serum 2, © Xfer Records.*

#### Включаем и загружаем звук

1. Кликни по заголовку осциллятора и выбери **Granular** в контекстном меню.
2. Если в этом осцилляторе уже стоял сэмпл в режиме Sample или Spectral, он сразу появится на дисплее. Иначе дисплей пустой.
3. Открой выпадающее меню сэмпла. В нём заводские тональные и нетональные сэмплы, а ещё вейвтейблы Serum: их тоже можно гранулировать. Свой файл грузится пунктом **Load Sample**. Обзоры пишут, что файл можно и просто перетащить на дисплей ([PML](https://www.productionmusiclive.com/blogs/news/how-to-use-granular-synthesis-in-serum-2)).
4. После загрузки то же меню покажет файл на диске или перезагрузит его.

Для дронов пригодится отключение трекинга высоты. Правый клик по заголовку осциллятора, снять **Enable Pitch Tracking**. Тогда режим Granular играет ноту C3 на любой клавише. Там же появится **Pitch Bend Tracking**: выключи и его, если колесо питча не должно трогать дрон.

#### Маркеры и операции с сэмплом

Наведи курсор на волну, и появятся маркеры начала и конца. Тащи их, чтобы запереть гранулятор в звоне ложки и выбросить стук. Это окно чтения из главы 4.

Правый клик по волне открывает меню операций. По руководству, почти все они совпадают с режимом Sample:

- **Snap Off / Snap to Zero / Snap to Beats / Snap to Loop.** Куда липнут маркеры: никуда, к нулевым переходам волны, к долям темпа, к точкам петли. Snap to Zero спасает от щелчков на краях.
- **Fade Edges.** Фейды на краях сэмпла, от 1 до 128 мс.
- **Normalize.** Поднимает громкость до пика без искажений.
- **Reverse.** Разворачивает весь сэмпл задом наперёд.
- **Trim.** Обрезает сэмпл по маркерам.
- **Slice Auto / Slice Manual.** Режет сэмпл по атакам и раскладывает куски по клавишам. Жёлтая линия на волне задаёт порог: ниже линия, больше кусков. В ручном режиме Alt-клик (на Mac Option-клик) добавляет или убирает разрез. В режиме петли Manual нарезка недоступна.
- **Show Marker Animation.** Маркеры двигаются вслед за модуляцией, видно, куда LFO гоняет окно.
- **Zoom to Start and End.** Фиксирует вид на весь файл. Пока пункт выключен, вертикальное движение мышью по волне меняет масштаб, горизонтальное листает.

Операции неразрушающие: исходный файл не меняется, работают отмена и повтор, а **Reload Sample** в меню сэмпла возвращает файл как был.

#### Меню петли

Меню петли решает, как гранулятор ходит по сэмплу. Большинство пунктов общие с режимом Sample, два есть только в Granular.

| Пункт | Что делает |
| --- | --- |
| One-shot | файл проходится вперёд один раз, пока держишь ноту |
| Fwd Loop | от маркера начала до конца петли, потом снова с начала петли |
| Rev Loop | дойдя до конца петли, идёт назад |
| Fwd/Rwd Loop | петля маятником: туда и обратно, без резких стыков |
| Tailed | играет вторую половину файла и зацикливает хвост, пока гаснет громкость |
| Relative Loop | петля едет вслед за маркером начала |
| Link Loop Length | при сдвиге начала петли её длина сохраняется |
| Exit Loop on Release | на отпускании клавиши выходит из петли и доигрывает файл |
| **Loop Grains** | только Granular: зёрна уважают маркеры петли |
| **Manual** | только Granular: позиция ставится руками (ниже) |

Маркеры петли синие, они появляются у верхнего края дисплея. Их можно тащить по отдельности, вместе (за промежуток между ними) или задавать числами в полях **LS** и **LE**. За маркеры начала и конца сэмпла петля не выходит. Зато если модуляцией или автоматизацией завести конец петли раньше начала, направление петли развернётся. Готовый приём для зёрен, которые то идут вперёд, то назад.

**Кроссфейд петли** в режиме Granular применяется к самим зёрнам и работает только при включённом Loop Grains. Кнопка кроссфейда тянется мышью вверх, светло-голубая кривая показывает его форму.

#### Режим Manual: позиция руками

Выбери **Manual** в меню петли. Курсор воспроизведения сменится красной точкой X|Y, а ручка **SCAN** начнёт двигать эту точку по горизонтали. При нажатии ноты сэмпл больше не сканируется: позиция стоит там, где точка. Это ручное движение и заморозка из главы 4 в чистом виде.

Позицию можно автоматизировать или модулировать: перетащи любой источник модуляции (LFO, огибающую, макрос) прямо на точку. Медленный LFO на точке даёт дрейф по звону ложки.

#### Пэд X|Y

В контекстном меню дисплея включи показ **X|Y Control**. На волне появится красная точка, а в меню новый пункт выбора параметра для оси Y. Варианты: Level, Warp, Warp 2, Density, Grain Length, Window Amt, Window Skew, а также случайность почти всего: Rand Offset, Rand Dir, Rand Pitch, Rand Length, Rand Pan, Rand Gain, Rand Window, Rand Skew, Rand Warp, Rand Warp 2. После выбора параметра появляется ещё один пункт: как именно ось Y его модулирует.

Повесь на Y длину зерна, включи Manual, и одним движением мыши ты гуляешь по ложке и меняешь её зернистость. На сцене это почти готовый инструмент.

#### SCAN: скорость скана

SCAN задаёт, как быстро курсор воспроизведения едет по сэмплу. Каждое новое зерно стартует с текущего места курсора. Высокая скорость раскидывает старты зёрен дальше по файлу, и они меньше перекрываются: подходит для ритма и глитча. Низкая скорость растягивает звук в дрон. Отрицательное значение разворачивает движение назад, ноль останавливает курсор: это заморозка.

Шкала в процентах. Чтобы найти исходный темп, загрузи запись речи и подбирай SCAN, пока слова не зазвучат в обычном темпе. От этой точки работает формула растяжения из главы 4.

Правый клик по SCAN открывает настройки:

- **Range.** Диапазон ручки: ±200% (по умолчанию), ±400% или ±800%.
- **Reverse.** Разворот скана. Его можно автоматизировать и модулировать.
- **Key Track.** Скорость скана растёт с высотой ноты. Выключен: скорость одна на всех клавишах.
- **Lock Scan Rate (to Tempo).** Скорость скана меняется вместе с темпом проекта.
- **Sample Length to BPM.** Длина сэмпла привязывается к темпу DAW, ручка SCAN превращается в **RATE** и задаётся в тактах и долях. Проход ложки займёт ровно такт или два.

#### DENS: плотность

DENS задаёт, как часто рождаются зёрна. Правый клик выбирает один из трёх режимов:

- **Free.** Частота зёрен в герцах. Это плотность из главы 6 в чистом виде.
- **BPM Sync.** Зерно на каждую долю темпа. В меню добавляются Triplet и Dotted для триолей и пунктира.
- **Grains.** Serum сам считает частоту зёрен по их длине так, чтобы одновременно звучало заданное число зёрен. Это перекрытие O из главы 2: поставил 4, и в каждый момент звучат четыре зерна, как ни крути длину.

Ещё две настройки в том же меню:

- **Jump Start.** Включён: на старте ноты сразу рождается много зёрен, полная плотность слышна мгновенно. Выключен: на старте одно зерно, облако набирается постепенно, и атака ноты мягче.
- **Max Grains.** Потолок одновременно звучащих зёрен, включая зёрна юнисона. Когда потолок достигнут, новое зерно пропускается, пока не освободится место. Главная ручка экономии процессора. Всего Serum умеет до 256 зёрен ([What's New](https://static.xferrecords.com/Serum%202%20What's%20New.pdf)).

В режиме Free частота зёрен доходит до звукового диапазона ([Databroth](https://www.databroth.com/blog/serum-2-review)), так что синхронный поток с тоном из главы 6 здесь достижим.

#### LENGTH: длина зерна

LENGTH задаёт длительность зерна. Правый клик выбирает режим:

- **Free.** Длина в секундах или миллисекундах.
- **BPM Sync.** Длина в долях такта, с Triplet и Dotted.
- **Percent.** Длина в процентах от периода между зёрнами. Недоступен, если у DENS выбран режим Grains.

Percent удобен для ритма. Длина в процентах от периода и есть перекрытие из главы 2, умноженное на сто: 50% дают зёрна с паузами, 100% встык, 200% по два зерна разом. Меняй плотность сколько угодно, характер нарезки сохранится.

#### Окно зерна

Кнопка окна открывает настройки огибающей зерна. Alt-перетаскивание кнопки (на Mac Option) быстро меняет AMOUNT и SKEW, не открывая настроек.

- **AMOUNT.** Насколько сильно форма окна влияет на зерно. Рядом поле случайности по зёрнам.
- **SKEW.** Перекос окна из главы 5. Тоже со случайностью по зёрнам.
- **SHAPE.** Форма окна, её картинка видна слева.

| Форма | Как устроена | Где пригодится |
| --- | --- | --- |
| Hann | плавный косинусный подъём и спад | рабочая форма для облаков и пэдов |
| Welch | параболический купол | собранное, плотное зерно с сильной серединой |
| Gaussian | колокол | мягкие, текучие текстуры |
| Blackman-Harris | крутые склоны, гладкий пик, края сильно гасятся | самый чистый звук при сильном перекрытии |
| Sinc | острый центр и колеблющиеся хвосты | необычная окраска, добавляет гармоник |
| Tukey | плоская середина, скруглённые края | больше исходника, разборчиво |
| Triangle | прямой подъём к пику, прямой спад | простое, чуть более острое зерно |
| Trapezoid | подъём, длинная полка, спад | ровное тело зерна, плотный звук |
| ExpDec | мгновенная атака, экспоненциальный спад | перкуссия, капли, щипки |
| Exp Dec Rev | экспоненциальный подъём, резкий пик | всасывание, обратные капли |

#### Случайность зёрен

Нижний ряд ручек отвечает за разброс по каждому зерну. Это набор из глав 4, 5, 7 и 8:

| Ручка | Что разбрасывает | Глава |
| --- | --- | --- |
| OFFSET | смещение позиции | 4 |
| DIR | направление зерна | 7 |
| PITCH | высоту | 7 |
| RAND (LENGTH) | длину | 5 |
| RAND (PAN) | панораму | 8 |
| RAND (LEVEL) | громкость | 8 |

Правый клик по **DIR** включает **Reverse Grains**: все зёрна разворачиваются задом наперёд разом. Переключатель можно автоматизировать, и тогда облако то идёт вперёд, то назад по команде. Ещё два разброса живут в настройках окна (AMOUNT и SKEW), и у обоих слотов Warp тоже есть случайность по зёрнам (Rand Warp и Rand Warp 2 в списке оси Y).

#### Высота

Высоту зёрен задают общие для всех осцилляторов ручки: **OCT** (октавы), **SEM** (полутоны), **FIN** (центы) и **CRS** (грубая плавная транспозиция без шагов, удобна как цель модуляции). Правый клик по OCT или SEM меняет режим: **Semitones**, **Harmonics** (кратные основному тону), **Ratio** (отношение частот, как в FM) и **Step** (шаги микротональной настройки MTS-ESP, появляется только при подключённом источнике настройки).

Совет из раздела о режиме Sample: если сэмпл звучит не на ноте C3, допиши ноту в конец имени файла через пробел или подчёркивание, например «lozhka F4.wav», и Serum сам поймёт корень. Приём описан для режима Sample, так что после загрузки в Granular проверь, подхватился ли корень.

#### Warp

Кнопка Warp открывает и прячет настройки искажения. По умолчанию Warp выключен, режим выбирается из меню или стрелками < >, глубина ручкой. Режимы те же, что у вейвтейблов: синхронизация, изгибы формы, фильтры, полтора десятка видов искажения, а ещё FM, PD, AM и кольцевая модуляция от другого осциллятора или фильтра. Слотов два (в списке оси Y они названы Warp и Warp 2).

Значит, облако из ложки можно частотно модулировать синусом из OSC B. Второй осциллятор для этого должен быть включён, но его громкость можно убрать в ноль. Так получаются колокольные и металлические облака, которых обычный гранулятор не даст.

#### Unison

UNISON складывает несколько гранулярных осцилляторов на одну ноту, каждый слегка расстроен. По обзору Databroth, голосов до 16 ([Databroth](https://www.databroth.com/blog/serum-2-review)). Настройки юнисона:

- **MODE.** Как расстроены голоса: Linear (ровно), Super (плотно, для «суперпил»), Exp (дальние голоса расходятся сильнее), Inv (нижние голоса расстроены сильнее), Random (случайно).
- **STACK.** Раскладка голосов по октавам. Варианты: Off, 12 (1-3x), 12+7 (1-3x), Center-12, Center-24.
- **DETUNE**, **RANGE**: величина и размах расстройки.
- **BLEND.** Баланс боковых голосов и центрального, по умолчанию 75%.
- **WIDTH.** Ширина юнисона в стерео.
- **START.** Случайный сдвиг стартовой позиции для каждого голоса. Голоса берут зёрна из разных мест, и звук оживает.
- **SPAN.** Фиксированный сдвиг стартовой позиции между голосами.
- **SPAWN PATTERN.** Когда голоса юнисона рождают свои зёрна. **Together** (по умолчанию): все разом. **Even**: равномерно в промежутке до следующего зерна. **Exp**: с растущими интервалами. **Random**: случайно.

SPAWN PATTERN стоит запомнить. С Together четыре голоса дают четыре зерна в одну и ту же миллисекунду. С Even те же четыре голоса заполняют паузы между зёрнами, и облако становится вчетверо гуще без единого изменения DENS.

Осторожно с процессором: юнисон, плотность и полифония перемножаются.

#### Модуляция

Проще всего назначать перетаскиванием. Тащи вкладку ENV или LFO, или селектор макроса, на нужную ручку: у курсора появится плюс над допустимой целью. Вокруг ручки появится синий ореол глубины, а маленький ореол слева сверху меняет глубину стрелкой. Глубину можно сделать и отрицательной. Второй способ: правый клик по ручке и выбор источника в меню.

Что есть в распоряжении:

- **4 огибающие**, с синхронизацией по темпу.
- **До 10 LFO** (с седьмого по десятый появляются, когда назначен шестой), с редактором формы, хаотическими режимами Lorenz и Rossler, частотой до 1000 Гц. Тысяча герц значит модуляцию звуковой частоты из врезки главы 9: LFO на высоте зерна начинает давать тембр.
- **8 макросов.** Макрос может управлять несколькими ручками сразу и сам может быть целью модуляции. Это связки из главы 9.
- **Сила нажатия и номер ноты** как отдельные источники.
- **Любой осциллятор или фильтр** как источник: перетащи его заголовок на ручку.

Все связи видны и правятся в матрице модуляции (страница **Matrix**). Наведи курсор на источник, и подсказка покажет, куда он назначен.

#### Как сохранить результат

Наведи курсор слева от логотипа Serum, появится значок волны. Перетащи его на аудиодорожку DAW, и Serum отрендерит последнюю сыгранную ноту или аккорд в WAV. Копия ложится в папку Renders, Alt-клик (Option-клик) по значку её открывает. Так тяжёлое облако превращается в лёгкий аудиофайл.

#### Рецепты на ложке

Везде начинай с чистого патча: главное меню, **Init Preset**. Затем OSC A в Granular, ложка загружена, маркеры начала и конца на звон.

**Рецепт 10.1. Ледяной пэд.**

1. LENGTH в режиме Free, около 120 мс. DENS в режиме Grains, значение 4.
2. SHAPE Hann. SCAN маленький положительный.
3. OFFSET немного, PITCH на 10–15 центов, RAND (PAN) на половину.
4. UNISON 3, SPAWN PATTERN Even, START немного.
5. Огибающая громкости: атака 1–2 секунды, отпускание 3–4 секунды.

**Рецепт 10.2. Капли.**

1. LENGTH в режиме Free, 20–40 мс. DENS в режиме Free, 3–6 Гц.
2. SHAPE ExpDec.
3. OFFSET почти на весь звон, RAND (LEVEL) заметно.
4. LFO в режиме Lorenz на FIN, малая глубина.

**Рецепт 10.3. Ритм-нарезка.**

1. Правый клик по SCAN, **Sample Length to BPM**, RATE на один такт.
2. DENS в режиме BPM Sync, 1/16.
3. LENGTH в режиме Percent, 50%.
4. DIR немного. Автоматизируй **Reverse Grains** на последнюю долю такта.

**Рецепт 10.4. Металлическое облако.**

1. Пэд из рецепта 10.1.
2. Включи OSC B, синус, громкость в ноль.
3. На OSC A в Warp выбери FM (B), глубину плавно поднимай.
4. OSC B на квинту выше, затем уводи на нецелые интервалы ручкой FIN. Ложка становится колоколом из другого мира.

**Рецепт 10.5. Органное мерцание.**

1. Пэд из рецепта 10.1.
2. UNISON 4, STACK 12+7, если этот вариант есть в твоей версии.
3. Макрос 1 на LENGTH с плюсом и на OFFSET с минусом. Крутишь макрос, и облако собирается в орган.

#### Упражнение 10.1. Ложка на пэде X|Y

1. Возьми рецепт 10.1, включи режим петли **Manual** и показ **X|Y Control**.
2. Ось Y назначь на Grain Length.
3. Запиши в DAW автоматизацию: минуту медленного движения точки.
4. Перетащи рендер в DAW и послушай отдельно. Это первый трек, сыгранный одной мышью.

### Глава 11. Ableton Granulator III

Granulator III написал Роберт Хенке, тот самый, что придумал первый Granulator, вместе с командой Ableton: Марко Тонни (интерфейс, реализация, управление проектом), Эрик Карл и Костя Кажев (дизайн интерфейса). Это третий инструмент серии, и Хенке называет его полностью новым. Хенке перечисляет главное: полная поддержка MPE, развёрнутая матрица модуляции, упрощённый интерфейс, захват звука прямо в инструмент без лишних устройств и монофонический режим.

> Granulator III продолжает обновляться вместе с Live, поэтому в новых версиях детали могут отличаться от описанных.

**Что нужно для запуска.** Хенке пишет, что инструменту нужен Live 12 Suite, а скачивается он с ableton.com из личного кабинета. Страница пака на сайте Ableton указывает требования шире: Live 12 Standard с Max for Live, версия 12.0 или новее. В пак входят 59 пресетов, Live-сет и подборка сэмплов, подходящих для гранулирования. Старый Granulator II по-прежнему доступен, но обновлять его, по словам Хенке, скорее всего уже не будут.

**Установка.** В браузере Live открой раздел Packs, найди Granulator III среди доступных паков (Available Packs) и установи. После установки он появится в разделе Packs наверху браузера.

**Push 3 Standalone.** Инструмент работает и там, но с ограничениями: нет картинки волны, сэмплы с самого Push не заменить (только играть пресеты, сделанные в Live), захват звука не работает.

#### Устройство интерфейса

Интерфейс состоит из трёх зон.

- **Главный дисплей.** Показывает либо сэмпл (с отметками старта зёрен, текущей позиции и размера зерна, плюс управление захватом), либо две огибающие, LFO и фильтр.
- **Дисплей модуляции.** Под главным. Показывает модуляции выбранного основного параметра, маленький треугольник указывает, какого именно. Набор модуляций у разных параметров разный: так движок работает экономнее, и каждую связь можно точнее подогнать.
- **Дисплей параметров.** Основные ручки.

Переключать главный дисплей можно кнопками **Display Selector** слева или режимом **Auto**. В Auto клик по любому параметру левее **Variation** показывает сэмпл, клик правее показывает огибающие. Стереосэмпл на картинке показан только левым каналом. Кнопки **(+)** и **(−)** справа внизу приближают и отдаляют волну вокруг Position, **(ALL)** возвращает весь файл.

#### Загружаем звук

Перетащи ложку на инструмент из браузера Live, из Session или из Arrangement. Это работает даже когда главный дисплей показывает огибающие, просто картинки не будет.

При загрузке и при захвате звук нормализуется: самое громкое место поднимается до 0 дБ. Тихая запись ложки зазвучит в полную силу без лишних действий.

#### Три режима зерна

Это первое, что надо выбрать: от режима зависит, как работают Grain Size, Shape и Variation.

**Classic.** Основан на Granulator II, самый гибкий и выразительный. На каждый стереоканал два перекрывающихся зерна с очень гибкой огибающей. Плотность здесь отдельной ручкой не задаётся: чем короче зерно, тем чаще они идут. По словам Хенке, зерно в 2 мс значит тысячу и больше перекрывающихся зёрен в секунду, и звук уходит в шум или в высокий тон. Это синхронный поток из главы 6.

**Loop.** Ближе всего к обычному сэмплеру: воспроизведение с кроссфейдами и случайной модуляцией позиции. Умеет играть длинные куски исходника без изменений. Подходит для ритмичного материала.

**Cloud.** Слои до 20 несинхронизированных зёрен. Хенке выделяет его для густых монофонических текстур. Это асинхронное облако из главы 2.

#### Position

Position решает, какой участок сэмпла играет каждое зерно. Шкала в процентах, поэтому позиция сохраняется относительно файла: загрузил другой сэмпл, и позиция осталась, скажем, на трети. Ставится ручкой или кликом прямо по волне.

Position модулируют LFO, Envelope 2, номер ноты (**Key**), сила нажатия (**Vel**) и все три параметра MPE. Плюс случайность по зёрнам через Variation.

#### Scan

В Granulator III скан устроен иначе, чем в Serum. Это рампа, которая двигает позицию от момента нажатия ноты.

- **Loop выключен.** Рампа останавливается в конечной точке.
- **Loop включён.** Дойдя до конца, рампа начинается заново.
- **Distance.** Конечная точка задаётся как расстояние от Position.

Если Position плюс текущее значение скана выходят за 100%, позиция заворачивается на начало файла. Хенке советует это для ритмичных лупов.

Скорость скана может зависеть от Key, Velocity и MPE Slide, её модулируют Envelope 2 и LFO. С включённым **Key** скорость скана растёт с высотой ноты, и на каждой ноте соотношение скана одинаковое. С выключенным скорость одна на всех нотах. Хенке советует сыграть аккорд и переключить Key туда-сюда: разница слышна сразу.

Вместе с Transpose и Grain Size скан даёт растяжение времени, сдвиг высоты и сложные искажения времени.

Шкала скана работает как множитель скорости. На 0 позиция стоит на месте, на 1 курсор идёт со скоростью самого сэмпла, на 0,25 вчетверо медленнее, и звук превращается в текстуру. Так что формула растяжения из главы 4 здесь работает напрямую: s равно значению Scan.

#### Grain Size

Главный параметр движка. Зерно бывает от 2 мс до 2 с. На 2 мс звук шумный или высокий и тональный, на 2 с из исходника читаются длинные куски, прежде чем начнётся следующее зерно.

Grain Size зависит от Key, Velocity, MPE Slide и Press, его модулируют LFO и Envelope 2, а Variation добавляет случайность размеру каждого зерна. Когда размер модулируется, новое значение вступает не сразу: инструмент старается сначала доиграть текущее зерно, чтобы не было щелчков. Как именно, зависит от режима.

Тонкость, о которой предупреждают оба видеоурока: Grain Size отмеряет кусок сэмпла, а слышимая длина зерна зависит от скорости чтения. Нота выше, сэмпл читается быстрее, и то же зерно звучит короче. Во втором уроке зерно в 76,1 мс на транспозиции +12 полутонов звучит вдвое короче.

Синхронизации с темпом у Grain Size нет. Обходной путь из второго урока: посчитать длину доли в миллисекундах и вписать вручную. Четверть длится 60 000 / BPM миллисекунд: при 120 BPM это 500 мс, восьмая 250 мс. Точно в долю зерно попадёт, когда транспозиция на нуле, а связь Transpose с клавишами выключена (о ней ниже).

В этом же разделе живут две ручки режимов:

- **Reverse** (только Loop). Вероятность, что зерно сыграет задом наперёд. 100% значит все зёрна обратные.
- **Density** (только Cloud). Сколько зёрен звучит одновременно: до 20 на стереоканал на ноту.

#### Shape

Shape это огибающая зерна, и в каждом режиме она своя.

- **Classic.** Одна ручка проходит всю линейку из главы 5: от резкой атаки с экспоненциальным спадом (перкуссия) через плавный кроссфейд (колокол) до экспоненциального подъёма с резким обрывом (обратная перкуссия).
- **Loop.** Shape задаёт длину кроссфейда в начале и в конце зерна. Ноль значит луп без кроссфейда, 100% значит фейд идёт постоянно.
- **Cloud.** Форма не регулируется, это экономия процессора.

Shape модулируют MPE Slide и Press, LFO и Envelope 2. Важная деталь: форма рассчитывается в начале каждого нового зерна. Поэтому длинные зёрна плюс быстрый ровный LFO на Shape дают сложные ритмические текстуры: каждое зерно получает свою форму. Бирюзовые бегущие линии на волне показывают, как форма действует на зёрна прямо сейчас.

#### Variation

Variation отвечает за случайность по зёрнам. Общая ручка задаёт, сколько случайности вообще, а отдельные параметры решают, что она трогает: **Position**, **Grain Size**, **Transpose** и **Volume**. Хенке описывает, что получается: статичные петли оживают, на маленьких зёрнах звук становится шумным, ритмичные лупы рассыпаются в гранулярное безумие.

Выбери ручку Variation, и на дисплее модуляции появятся оранжевые ручки целей. По умолчанию поднята только Position. Transpose там подписан коротко: TR.

Тонкости, которые стоит знать:

- **Разброс позиции абсолютный:** от нуля до двух секунд, вне зависимости от длины сэмпла. И всегда положительный: зёрна отскакивают только вперёд.
- **Остальные разбросы двусторонние.**
- **Разброс высоты пока работает только в режиме Cloud**, и отрицательные значения не действуют. Хенке пишет, что это может измениться в обновлениях.

Variation модулируют MPE Slide и Press, LFO, Envelope 2, Key и Velocity. Например, сила нажатия на Variation: тихие ноты чистые, громкие рассыпаются.

#### Transpose, Tune и тонкости строя

**Transpose** задаёт общий строй зёрен, **Tune** точную подстройку. Обычно высота следует за нотами с **Key** на 100%, но масштаб можно изменить. Высоту модулируют Note Pitch Bend, MPE Press, Envelope 2, LFO и случайное значение в момент нажатия ноты. Разброс высоты по зёрнам продублирован здесь же для удобства.

**Строй сэмпла.** Granulator, как любой сэмплер, считает, что в загруженном файле звучит нота C. Нажал C, и сэмпл играет на своей исходной скорости. Если ложка звучит на E, опусти Transpose на −4 полутона и подтяни Tune. Узнать ноту ложки проще всего тюнером: поставь Tuner из Live сразу после Granulator III и сыграй C.

**Одна высота на всех клавишах.** Для дронов и нарезок транспозиция по клавишам часто мешает. Выбери Transpose, на дисплее модуляции поставь Key в 0: все ноты зазвучат на одной высоте. Такая же связь Key на 100% стоит у частоты фильтра, её тоже стоит обнулить, иначе фильтр будет ездить с каждой нотой. Питч-бенд при этом по-прежнему двигает высоту, и его можно рисовать автоматизацией в клипе.

Хенке отдельно объясняет строй, и это стоит пересказать. Сэмпл на ноте C3 играет со своей исходной скоростью. Если в нём звучит C3, всё просто. Если C#3, опусти на полутон. Но в гранулярном синтезе короткие куски повторяются очень часто, и слышимая высота становится странной смесью высоты исходника и размера зерна. Предсказать её простым способом нельзя, надо пробовать. Нужные ручки в разделах Transpose и Grain Size.

**Приём Хенке: высота из размера зерна.** Поставь **Transpose Key** в 0, а **Grain Size Key** в 100. Теперь все ноты играют сэмпл на одной высоте, но размер зерна меняется с нотой, и рождается отчётливое ощущение высоты. Чтобы попасть в строй, Хенке советует размер ровно 3,822 мс. Число не случайное: период 3,822 мс соответствует частоте около 261,6 Гц, ноте до первой октавы (в Live она называется C3). Это прямая демонстрация главы 6: нота рождается из частоты зёрен.

**MPE и микротональность.** Если работаешь с тональным материалом и хочешь, чтобы инструмент правильно принимал питч-бенд MPE и строи Live 12, поставь **Note Pitch Bend** в разделе Transpose на 48 полутонов.

#### Spread

Spread расстраивает левый и правый каналы зёрен. Даже небольшое значение даёт стереохорус, но главное в другом: левые и правые зёрна перестают совпадать по времени старта, и все разбросы Variation получают в каналах разные значения. Звук становится очень стереофоничным. Большие значения дают заметно разную высоту слева и справа. Spread модулируют Velocity, MPE Slide и Pressure, Envelope 2 и LFO.

#### LFO

Стерео-LFO с тремя способами работы:

- **по темпу:** от 1/16 до 2 тактов;
- **свободно:** от 0,01 до 20 Гц;
- **в звуковом диапазоне:** для FM-подобных эффектов и сложных шумов. Это модуляция звуковой частоты из врезки главы 9.

Формы: Sine, Triangle, Up, Down, Rect, Sample & Hold (случайные ступени) и два вида плавной случайности, Rand и Move. Форма выбирается меню или кликом по иконке формы. LFO стартует с заданной фазы (**Phase**) или со случайной.

- **Stereo.** Сдвиг фазы между каналами: 0° (моно), 90° (полностью вне фазы), 180° (перевёрнутое моно).
- **Частота LFO** модулируется Note Pitch Bend и Slide, Envelope 2, Key, Velocity и случайным значением при нажатии ноты.
- **Глубина LFO** модулируется Slide и Pressure, Envelope 2, Key и Velocity. Опция **Use Mod Wheel** добавляет масштабирование колесом модуляции (MIDI CC 2).
- **Quant.** Квантует выход LFO до регулировки глубины и делает ступенчатую модуляцию. Пример Хенке: при Quant 0,5 рампа даёт три значения (0; 0,5; 1), а синус пять (от −1 до 1 с шагом 0,5). Разница потому, что рампы Up и Down однополярные (от 0 до 1), а остальные формы двуполярные (от −1 до 1).

Ручка Stereo особенно хороша на Position и Grain Size: с фазовым сдвигом LFO двигает позицию и размер зерна по-разному в левом и правом ухе, и облако расслаивается на два.

#### Фильтр

Два фильтра SVF последовательно, девять режимов: 24 дБ LP, 12 дБ LP, 12 дБ LP в 12 дБ HP, 12 дБ LP с режекцией, одна режекция, две режекции, 12 дБ HP с режекцией, 12 дБ HP, 24 дБ HP. Клик по иконке листает типы. Фильтр можно выключить и сэкономить процессор.

- **Width.** Во всех режимах, кроме 12 дБ LP, 12 дБ Notch и 12 дБ HP, сдвигает частоту второго фильтра. Обычно полезны отрицательные значения: например, в паре LP и режекция вырез работает, только если он ниже среза LP.
- **Resonance.** В двойных режимах действует только на главный фильтр, у второго она фиксирована.
- **Модуляция частоты:** все три параметра MPE, огибающая громкости и Envelope 2, Key, Velocity и LFO.

По умолчанию частота фильтра привязана к Key на 100%: фильтр едет за транспозицией и продолжает убирать или подчёркивать одни и те же гармоники исходника на любой ноте.

#### Громкость и огибающие

Громкость модулируют Key, Velocity, MPE Slide и Press и LFO. Разброс громкости по зёрнам продублирован здесь.

Огибающих две. **Envelope 1** управляет громкостью и может двигать частоту фильтра. **Envelope 2** общий источник для множества параметров. У обеих очень длинные атака, спад и отпускание, для медленно меняющихся звуков. У каждой свой параметр **Key**: скорость огибающей зависит от высоты ноты, и высокие ноты могут затухать быстрее, как у живых инструментов.

Приём из второго урока: Envelope 2 со спадом около секунды и отрицательной глубиной сразу на Shape и Grain Size. На атаке ноты зёрна острые и мелкие, потом возвращаются к обычным. У звука появляется щелчок в начале, как у щипковых.

#### Голоса, Glide и Hold

- **Полифония** фиксированная, 8 голосов.
- **Моно-режим.** В нём **Glide** действует на все модуляции сразу, и ноты плавно перетекают друг в друга. Glide работает только на перекрывающихся нотах, время от 0 до 2 секунд.
- **Hold.** Удерживает последние сыгранные ноты, как в арпеджиаторе. Сыграл аккорд, отпустил клавиши и крутишь ручки обеими руками. Новая нота после полного отпускания всех клавиш сбрасывает удержанные. В Granulator II Hold работал иначе.

#### Capture: живой вход

Capture превращает Granulator III в гранулятор живого звука.

1. Включи захват кнопкой **I/O**. Сэмпл пока не меняется, появляется только интерфейс записи.
2. Выбери источник двумя меню **Source**. Можно взять даже выход самого Granulator III и ресэмплить себя.
3. Инструмент постоянно пишет последние несколько секунд звука, сколько именно, задаёт меню **Length**.
4. Нажми **Capture**: текущий сэмпл заменится снимком последних секунд. Настройки ручек не меняются.
5. **Cancel** возвращает последний загруженный сэмпл, даже если ты нажимал Capture много раз.
6. **Save** открывает диалог сохранения: инструмент запишет файл и перезагрузит его как обычный сэмпл.

Важно: несохранённый захват пропадёт при следующем открытии проекта, вместо него загрузится последний загруженный сэмпл.

Источником захвата может быть другая дорожка Live или внешний вход: микрофон, железный синтезатор. Второе меню Source выбирает точку съёма сигнала, во втором уроке выбран сигнал после эффектов.

**Генеративный ресэмплинг** (второй урок). Granulator III стоит на своей дорожке и захватывает соседнюю дорожку с барабанами. LFO-устройство в прямоугольном режиме назначено на кнопку Capture и нажимает её каждые два такта, так что гранулятор сам обновляет материал. На Scan 1 захваченное звучит почти как есть, на Scan 0,25 превращается в текстуру. Добавь LFO на Grain Size и Shape, и получится инструмент для живого выступления, который сам себя кормит.

#### Рецепты на ложке

Совет из первого урока: настрой ручки на одном сэмпле, а потом подменяй сэмплы и слушай. Звук во многом решает исходник, и одна настройка на разных файлах даёт совсем разные результаты.

**Рецепт 11.1. Пэд в Classic.**

1. Режим Classic. Position на середину звона.
2. Grain Size около 100 мс, Shape посередине (плавный кроссфейд).
3. Variation немного, на Position.
4. Spread чуть-чуть, для стерео.
5. Envelope 1: атака 2 секунды, отпускание 4 секунды. Включи Hold, возьми аккорд и отпусти клавиши.

**Рецепт 11.2. Ложка-синтезатор.**

1. Режим Classic, Position в звон.
2. Transpose Key 0, Grain Size Key 100, Grain Size 3,822 мс.
3. Сыграй мелодию: высоту задаёт размер зерна, а окраску звон ложки.
4. Добавь немного Variation на Grain Size, тон станет шершавым.

**Рецепт 11.3. Рваный ритм в Loop.**

1. Режим Loop. Grain Size 100–200 мс.
2. Reverse 30%.
3. LFO в режиме по темпу, форма Sample & Hold, 1/16, на Position.
4. Shape поменьше, чтобы кроссфейды не размазали атаки.

**Рецепт 11.4. Облако в Cloud.**

1. Режим Cloud. Density около 12.
2. Grain Size 150–300 мс.
3. Variation заметно: Position на 300–500 мс, Transpose на пару полутонов.
4. Spread побольше. Сверху реверб с длинным хвостом.

**Рецепт 11.5. Нарезка по клавишам.**

1. Загрузи длинный звук: фразу, полевую запись, сессию импровизации с синтом.
2. Transpose Key в 0, Key у частоты фильтра в 0.
3. Выбери Position и на дисплее модуляции подними Key. Теперь каждая клавиша берёт свой кусок сэмпла. Похоже на нарезку Simpler, только без привязки к атакам. Насколько сдвигается позиция на одну клавишу, по шкале не понять: подбирай на слух.
4. Включи моно и Glide. При игре легато позиция будет плыть от куска к куску.
5. Режим Cloud и Grain Size поменьше: смена позиции станет слышна быстрее.

#### Упражнение 11.1. Гранулятор собственного голоса

1. Включи I/O, в Source выбери вход с микрофоном.
2. Скажи в микрофон «ложка» несколько раз, растягивая гласную.
3. Нажми Capture. Если не понравилось, говори снова и жми Capture ещё раз.
4. Включи Scan с Loop, Distance на длину одного слова. Hold, одна нота.
5. Удачный захват сохрани кнопкой Save, иначе он пропадёт.

### Глава 12. Arturia Pigments

В Pigments гранулятор встроен в движок сэмплов (Sample engine). У синтезатора два основных слота движков, и в каждом может стоять один из пяти типов: Analog, Wavetable, Sample, Harmonic и Modal. Поставь Sample в оба слота, и получишь два независимых гранулятора в одном патче. Гранулярный режим появился ещё во второй версии Pigments, вместе с поддержкой MPE.

> Описание соответствует Pigments 7.0.0. Диапазоны с пометкой «по руководству Pigments 2» взяты из документации второй версии и в новых версиях могли измениться.

*Скриншот 12.1. Движок Sample в режиме Main, гранулярная секция включена. Интерфейс Pigments, © Arturia.*

#### Загружаем звук

У движка Sample шесть слотов для сэмплов, A–F, их превью видны под картинкой волны. Клик по превью пустого слота открывает браузер сэмплов.

Свой звук попадает в Pigments через папку. В браузере сэмплов нажми **Add Folder** справа внизу и укажи папку с ложкой. Папка появится в левой колонке браузера рядом с заводскими банками. Форматы: WAV или AIFF, 16 или 24 бита, от 44,1 до 192 кГц. Длина сэмпла ограничена только оперативной памятью.

В браузере можно слушать сэмплы до загрузки: иконка наушников вверху правой колонки включает прослушивание, ручка рядом задаёт его громкость. Один клик выбирает сэмпл и оставляет браузер открытым, двойной клик загружает и закрывает.

#### Три вида дисплея

Над волной три кнопки:

- **Main.** Под волной видна гранулярная секция. Показан только участок между маркерами обрезки.
- **Edit.** Строй, направление, петля и громкость слота. Здесь же ставятся маркеры обрезки.
- **Map.** Как сэмплы из шести слотов раскладываются по клавишам и скорости нажатия.

| Параметр из части 2 | Где в Pigments |
| --- | --- |
| Окно чтения (глава 4) | маркеры обрезки Trim Start и Trim Stop в режиме Edit |
| Позиция (глава 4) | ручка **Start** в секции Sample/Grain, синяя линия на волне |
| Скан (глава 4) | ручка **Scan** |
| Разброс позиции (глава 4) | рандомайзер **Start** |
| Размер (глава 5) | ручка **Size** и её режимы |
| Огибающая (глава 5) | ручка **Shape** и меню форм |
| Плотность (глава 6) | ручка **Density**, режим Hertz или по темпу |
| Разброс плотности, синхронность (глава 6) | рандомайзер **Density** |

#### Включаем гранулярный режим

В режиме Main под волной стоит секция **Granular** с кнопкой включения в заголовке. Пока она выключена, движок работает как обычный сэмплер. Справа в заголовке поле **Limit**: максимум одновременно перекрывающихся зёрен. Руководство Pigments 7 называет его одним из главных способов сдержать процессор на высокой плотности. По руководству Pigments 2, лимит ставится от 3 до 256.

Верхний ряд ручек задаёт главное в зёрнах, нижний разбрасывает их случайно.

#### Start: позиция

Позиция в Pigments живёт по соседству с гранулярной секцией, в секции **Sample/Grain**. Ручка **Start** задаёт точку, откуда играет сэмпл или рождаются зёрна, в пределах между маркерами обрезки. На волне это вертикальная синяя линия. Там же ручка **Volume**: громкость сэмпла или зерна.

Соседняя секция **Output** отвечает за движок в целом: общая громкость и **Filter Mix**, распределение сигнала между фильтрами 1 и 2.

#### Scan

Scan двигает «головку» по потоку зёрен. Руководство даёт опорные точки:

- **12 часов:** скана нет, заморозка.
- **Плюс:** точка старта едет вперёд во времени.
- **Минус:** назад.
- **±100%:** скорость скана равна скорости воспроизведения зёрен. Остальные проценты ускоряют или замедляют скан относительно этой скорости.

Формула растяжения из главы 4 работает, если считать 100% исходной скоростью. Руководство советует не гадать, а слушать.

#### Density

Density задаёт частоту рождения зёрен. Клик по синему овалу под ручкой открывает меню **Density Type**: **Hertz** (свободно, в герцах) и варианты по темпу: **Sync**, **Straight only**, **Triplets only**, **Dotted only**. В режиме Hertz число на ручке и есть зёрна в секунду: 1 Гц значит одно зерно в секунду.

Совет из руководства: учись на низкой плотности, там лучше слышно, что происходит.

#### Shape: огибающая зерна

Клик по иконке формы над третьей ручкой открывает меню **Grain Envelope Shape**: Triangle, Trapezoid, Tukey, Gaussian, Sinc, Expodec, Rexpodec, Smooth Exp. Меню выбирает форму, а ручка **Shape** гнёт её дальше. По руководству Pigments 2, ручка переводит форму от «гладкой» к «щёлкающей», и её можно модулировать.

| Форма | Как устроена | Глава 5 |
| --- | --- | --- |
| Triangle | прямой подъём, прямой спад | треугольник |
| Trapezoid | подъём, полка, спад | трапеция |
| Tukey | плоская середина, скруглённые края | трапеция с мягкими краями |
| Gaussian | колокол | гаусс |
| Sinc | острый центр, колеблющиеся хвосты | особая окраска |
| Expodec | резкая атака, экспоненциальный спад | перкуссия |
| Rexpodec | экспоненциальный подъём, резкий конец | обратная перкуссия |
| Smooth Exp. | сглаженная экспонента | мягкая перкуссия |

Разница между формами сильнее всего слышна на коротких зёрнах: сравни их на слух при длине 10–30 мс.

#### Size: длина зерна

Меню под ручкой Size выбирает, в чём она меряется:

- **Percentage.** Процент от максимального размера зерна.
- **Time Division.** Доля периода текущей плотности. Это перекрытие из главы 2: длина зерна привязана к расстоянию между зёрнами, и характер облака сохраняется при любой плотности.
- **Straight Only**, **Triplets Only**, **Dotted Only.** По темпу: ровные доли, триоли, пунктир.
- **Time.** Абсолютное время в миллисекундах. По руководству Pigments 2, от 1 мс до 1 секунды.

Руководство отдельно напоминает: зёрна перекрываются, и это важная часть гранулярного характера. Сколько их перекрывается максимум, решает Limit.

#### Рандомайзеры

Нижний ряд ручек добавляет случайность. У большинства есть меню направления: кнопка или иконка рядом с ручкой.

| Ручка | Что разбрасывает | Варианты меню | Глава |
| --- | --- | --- | --- |
| Start | позицию: зёрна рождаются до, после или вокруг точки старта | Before, After, Both | 4 |
| Pitch | высоту зёрен; по руководству Pigments 2, до 3 октав | Up, Down, Both | 7 |
| Density | плотность: добавляет или убирает зёрна | More Dense, Less Dense | 6 |
| Direction | долю обратных зёрен | нет | 7 |
| Size | длину зёрен | Shorter, Longer, Both | 5 |
| Stereo | панораму | Pan, Width | 8 |
| Volume | громкость зёрен | нет | 8 |

Две тонкости:

- **Direction**, по руководству Pigments 2: крайнее правое положение играет зёрна вперёд, крайнее левое назад, середина даёт пятьдесят на пятьдесят.
- **Stereo в режиме Width** разносит по стерео уже рандомизированные зёрна. Если других разбросов нет, все зёрна остаются в центре даже при Width на максимуме. Руководство Pigments 2 уточняет: Width добавляет разницу между левым и правым каналом для разбросов Size, Pitch и Start. Так что Width работает только в паре с другими рандомайзерами.

#### Шесть сэмплов и зёрна

Вот возможность, которой нет у двух других инструментов книги. Режим **Map** раскладывает слоты A–F, и два его варианта работают по зёрнам:

- **Round Robin.** Слоты играют по кругу. С включённой гранулярной секцией каждое новое зерно берётся из следующего сэмпла.
- **Random.** Сэмпл выбирается случайно. С гранулярной секцией каждое зерно берётся из случайного слота.

Загрузи в шесть слотов шесть разных записей, и облако будет плести их между собой зерно за зерном. Остальные режимы Map: **Single** (один сэмпл на всю клавиатуру), **Key Map** (слоты разложены по клавиатуре), **Key/Velo Map** (по клавишам и двум слоям силы нажатия), **Sample Pick** (сэмпл выбирает ручка, её можно модулировать).

#### Режим Edit: строй и маркеры

Выбери слот кнопкой A–F и настрой:

- **Tune.** **Transpose** ±36 полутонов, **Fine** ±1 полутон с шагом в цент, **Root Note** (корневая нота сэмпла).
- **Playback.** **Play Mode**: вперёд (Normal) или назад (Reverse). **Loop** включает петлю, **Loop Mode** выбирает вперёд (Forward) или маятником (F&B), **Loop Fade** делает кроссфейд петли (только в Forward), кнопка **r** держит петлю на отпускании ноты.
- **Mix.** **Gain** и **Pan** слота.
- **Slot.** **Copy** копирует сэмпл в другой слот, чтобы держать его с другими настройками. **Reset** сбрасывает слот, **Clear** очищает.

Маркеры обрезки (Trim Start и Trim Stop) стоят вертикальными линиями с треугольными ручками сверху, маркеры петли с ручками снизу. Это окно чтения из главы 4: запри ложку в звоне. Кнопка **Snap** над дисплеем примагничивает маркеры к нулевым переходам волны и спасает от щелчков. Для стереосэмплов допуск шире, потому что точных нулей у них может не быть.

Root Note подтянется сам, если корневая нота записана в метаданных WAV-файла. Маркеры обрезки и петли тоже берутся из метаданных, если они есть.

#### Tune движка и фильтр сэмпла

Секция Tune движка задаёт общий строй голосов. У движка Sample в ней есть ручка **Filter**: фильтр прямо на сэмпле, раньше всей остальной обработки. Влево от 12 часов опускает срез низкочастотного фильтра, вправо поднимает срез высокочастотного, на 12 часах фильтра нет. Удобно срезать гул или шипение ложки до гранулятора.

#### Unison и Shaper

Под секцией Tune стоит секция Unison/Shaper. Клик по её названию открывает меню режимов.

- **Unison, Chord, Super.** Работают так же, как в других движках. В режиме Chord голоса юнисона квантуются по полутонам в один из 12 классических аккордов: одна клавиша даёт облако-аккорд. В аналоговом движке руководство указывает до 8 голосов юнисона.
- **Resonator.** Шесть параллельных полосовых фильтров, первый настроен по ноте и секции Tune, остальные по гармоникам от него. В гранулярном режиме резонатор следует за высотой зёрен, даже со случайной высотой. Ручки: **Coarse** (настройка), **Wet/Dry**, **Resonance** (резонанс и длина звона), **Inharm**: в нуле резонаторы стоят на гармониках, выше нуля расходятся, ниже сходятся. Негармонический строй даёт колокола и металл.
- **BitCrush.** **Decimate** (понижение частоты дискретизации), **Bit Depth** (разрядность), **Key Track** (Decimate следует за клавишей).
- **Modulation.** **Freq Mod** (линейная FM через ноль) и **Ring Mod**. Источник модуляции: осциллятор-модулятор движка или другой основной движок.

#### Модуляция

Модуляцию назначают перетаскиванием. В полосе обзора модуляции наведи курсор на название источника, оно сменится на **Assign**. Тащи на нужную ручку: все допустимые цели обведены серым. Глубину потом меняешь на кольце вокруг ручки.

Источники по вкладкам:

- **Keyboard:** скорость нажатия, послекасание, трекинг клавиатуры, колёса.
- **Envelopes:** три огибающие, первая всегда на громкости. Все огибающие Pigments, по руководству, способны работать на звуковой частоте.
- **LFO:** три.
- **Functions:** три многоточечные функции, сложные кривые любой формы.
- **Random:** три генератора с режимами Random, Voice Modulator, Turing, Sample & Hold, Binary.
- **Combinate:** смешивают другие источники.
- **Macros:** четыре макроса M1–M4.

Главная гранулярная фишка модуляции: у LFO и Functions в меню перезапуска (Retrig Source) есть пункты **Engine 1 Grain** и **Engine 2 Grain**. Они появляются, когда в слоте стоит движок Sample с включённой гранулярной секцией. LFO, перезапущенный каждым зерном, даёт каждому зерну свою собственную кривую модуляции. Повесь такую Function на фильтр, и каждое зерно получит свой спад фильтра.

#### Бонус: гранулярный экзайтер Modal

В движке Modal, физической модели резонирующих предметов, есть возбудитель Friction с режимом **Granular**. Он берёт часть настроек гранулятора Sample с фиксированными значениями и бьёт по резонатору зёрнами. Выбираешь тип сэмпла-источника, громкость (**Volume**), сдвиг высоты (**Tune**) и частоту зёрен (**Rate**, в герцах или по темпу). Руководство советует модулировать Rate через LFO, Function или Random.

#### Рецепты на ложке

Везде: движок Sample в слоте 1, ложка загружена через Add Folder, режим Main, гранулярная секция включена, маркеры обрезки на звоне.

**Рецепт 12.1. Пэд.**

1. Start на середину звона. Scan чуть вправо от 12 часов.
2. Density в режиме Hertz, около 30.
3. Size в режиме Time, около 120 мс. Форма Gaussian.
4. Рандомайзеры: Start (Both) немного, Pitch (Both) чуть-чуть, Stereo (Pan) на половину, Volume немного.
5. Envelope 1: долгая атака, долгое отпускание.

**Рецепт 12.2. Капли.**

1. Density в режиме Hertz, 3–6.
2. Size в режиме Time, 20–40 мс. Форма Expodec.
3. Рандомайзеры: Start (Both) сильно, Density (Less Dense) заметно, Volume заметно.

**Рецепт 12.3. Колокола.**

1. Пэд из рецепта 12.1.
2. В Unison/Shaper выбери Resonator, Wet/Dry посередине.
3. Подними Resonance для долгого звона.
4. Уводи Inharm вверх: ложка зазвучит колоколами. Рандомайзер Pitch резонатор подхватит.

**Рецепт 12.4. Шесть ложек.**

1. Запиши ещё пять звуков: ложка о стакан, о кастрюлю, о стол, о бутылку, о подоконник.
2. Загрузи все шесть в слоты A–F.
3. В режиме Map выбери Random.
4. Включи гранулярную секцию: каждое зерно берётся из случайной записи, облако становится кухней.

**Рецепт 12.5. Зерно со своим фильтром.**

1. Density по темпу, Straight only, 1/16. Size в режиме Time Division.
2. Function 1: короткий спад от максимума к нулю. Retrig Source: Engine 1 Grain.
3. Назначь Function 1 на частоту фильтра 1.
4. Каждое зерно получает свой взмах фильтра, и ровная сетка шестнадцатых начинает квакать.

#### Упражнение 12.1. Одна настройка, шесть слотов

1. Собери рецепт 12.1 на ложке.
2. Кнопкой Copy размножь ложку в слоты B и C, в каждом поменяй Transpose: ноль, плюс квинта, плюс октава.
3. Режим Map: Round Robin. Зёрна будут по кругу брать три транспозиции одного звука.
4. Сравни с режимом Random. Запиши оба варианта и послушай подряд.
